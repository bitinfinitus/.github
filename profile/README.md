<h3 align="center">Do bit ao infinito.</h3>

<p align="center">
  Desenvolvimento de software sob medida: sistemas web, apps e APIs.
</p>

<br>

**bitinfinitus** junta duas palavras. *Bit* é a menor unidade de informação: um 0 ou um 1, o ponto de partida de todo software. *Infinitus* é latim para "sem fim". O menor e o ilimitado no mesmo nome.

## O que fazemos

| | |
|---|---|
| **Sistemas web** | Plataformas, painéis e sistemas internos que rodam no navegador. |
| **Apps** | Aplicativos para celular, para o seu cliente ou para a sua equipe. |
| **APIs** | Integrações e serviços que conectam sistemas e trocam dados com segurança. |

## Como trabalhamos

Todo sistema começa pequeno: uma função, uma tela, um bit. O que separa um bom software de um problema futuro é ter sido construído para crescer.

- **Começamos simples.** A primeira versão resolve o problema principal, sem excesso.
- **Entregamos cedo.** Você vê o software funcionando desde as primeiras semanas.
- **Evoluímos em ciclos curtos.** O sistema acompanha cada nova fase do negócio, sem precisar ser reescrito do zero.

## O símbolo

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/bitinfinitus/.github/main/profile/assets/bitinfinitus-simbolo-negativo.svg">
  <img alt="Símbolo bitinfinitus" src="https://raw.githubusercontent.com/bitinfinitus/.github/main/profile/assets/bitinfinitus-simbolo.svg" width="96" align="left">
</picture>

Um "b" que não termina. A haste desce, dobra em ângulo reto e fecha o infinito num traço contínuo. Só retas, cantos de raio fixo e diagonais de 45°, numa grade de 8 unidades, como uma trilha de circuito impresso.
